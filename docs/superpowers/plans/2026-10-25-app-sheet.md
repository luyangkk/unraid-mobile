# AppSheet and Disk Details Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open current read-only disk details in a reusable accessible AppSheet.

**Architecture:** Radix primitives remain in ui/sheet; AppSheet owns modality,
presentation, focus return and Motion gestures. Storage holds a selected name
and resolves it against each incoming snapshot without creating queries.

**Tech Stack:** React 19, TypeScript, Radix Dialog, Motion, Vitest/jsdom.

**Spec:** `docs/superpowers/specs/2026-10-25-app-sheet-design.md`

## Global Constraints

- Add only `@radix-ui/react-dialog` and `motion`; retain existing package versions.
- Features import AppSheet, never Radix primitives.
- At most `max-w-md`, 44px targets, bottom safe area, independent body scrolling.
- No API, two-second polling, write capability, URL/localStorage or offline-data changes.
- Use existing `formatBytes`/`formatRate`; standby always displays `Temp —`.
- Add English function comments. Do not change existing live validation artifacts.

## Review Focus

- Tap focus differs from desktop click focus: explicit trigger restoration.
- Trigger disappears during a poll: show missing disk and restore summary focus.
- Long device/name fields at 320px: wrapping without horizontal overflow.
- Reduced motion changes while open: disable drag and remove translation.
- Exit/reopening/unmounting: no leaked modal, scroll lock or focus trap.
