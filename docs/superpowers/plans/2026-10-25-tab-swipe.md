# Primary Tab Swipe Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for the coupled Shell integration, with one independent final review.

**Goal:** Add single-touch adjacent Tab navigation and subtle entry transitions.

**Architecture:** Shared static destinations, Shell-owned native gesture refs,
real DOM/modal checks and a stable single-Outlet opacity animation.

**Tech Stack:** React 19, TanStack Router/Query, Motion, Vitest, Pointer Events.

**Spec:** `docs/superpowers/specs/2026-10-25-tab-swipe-design.md`

## Global Constraints

- One Outlet, persistent Shell, no exit route, keys, preload or dependency changes.
- `/`, `/docker`, `/vm`, `/storage`; left next, right previous, no wrap.
- 12px direction lock, 1.5 horizontal ratio, 60px distance, 24px/600px/s flick,
  24px viewport edge exclusion; ref-only pointer state.
- Preserve Home's Docker/VM/Storage observers and existing intervals/SSE/cache.
- Sheet Portal and exiting DOM block starts/submission; no lifted selection.
- Reduced motion disables Tab animation while retaining Tab swipe.

## Review Focus

- Captured Sheet pointerup must never submit a previously held Tab gesture.
- Edge-boundary nav swipe consumes only its own click, not keyboard or later taps.
- Lazy/pending navigation and superseding clicks must not queue gestures.
- Repeated snapshots must not restart entry animation or rebind pointer state.
- Background/401/unmount discard gestures even if the pointer later ends.
