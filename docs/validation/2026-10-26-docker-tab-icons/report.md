# Docker 页容器图标补全

日期：2026-10-26。此前 Docker 页的 `ContainerRow` 固定绘制通用 Box，虽然 API 已提供 `iconVersion`，该页面没有调用图片加载器。本次让 Running、Stopped 和 Other 行复用 Home 的受认证容器图标，保持原有 40px 图标位置和指标布局。

图标继续通过同源 API 读取当前缓存 PNG，使用 Bearer Header、取消信号和 `no-store`。缺失或加载失败时显示通用图标，不新增图标地址推断、外部下载、容器点击行为或动作按钮。Home 保持 32px 图标和现有 FolderView2 聚合规则。

Running 折叠偏好保持原样，Stopped 仍默认折叠。两组均在展开后才发起图片请求，已加载图片在收起、轮询和重新展开时复用。Docker 页使用 Shell 的前后台与在线状态控制图片请求；后台和离线期间不发起新请求，保留已经加载的图片。取消、Blob 释放和认证失效处理沿用通用加载器。

发布前审查发现，Stopped 展开后经历采集不可用或列表清空，再恢复时，展开状态与重新挂载的 `details` 可能失步。现在 `open` 与展开状态保持一致，恢复时保留此前的选择，避免在折叠状态下请求图片。
