## Production Chrome checks

The browser script runs built `web/dist` through the production Go frontend/API
handler with a temporary Go overlay. All host readers use synthetic fixtures;
it does not contact Unraid, Docker Engine or libvirt. The test token is disposable.
Chrome uses native CDP `Input.dispatchTouchEvent`, actual browser click generation
and scrolling at 390px and 320px. Service Workers are blocked for these UI checks;
worker behavior is checked separately by the build verification.

The final **16 passed checks**, with no page errors, in
`2026-10-25-tab-swipe/browser-results.json` cover six adjacent
destinations; one stable main; rendered opacity frames; no fade on metrics;
bottom swipe and subsequent tap; boundary History; browser back/forward;
viewport edge and cancellation; vertical scrolling; Sheet right swipe and handle
drag with focus/scroll return; no added SSE or capabilities reads; a delayed
actual lazy route chunk with Router pending UI, ignored swipes and superseding
links; and reduced motion without overflow at 320px.

The final run was performed again on the production build after both gesture
fixes. The first browser runs exposed timing and fixture assumptions in the check
script: input before the Shell effect was installed, sampling before the previous
entry finished, and scrolling a collapsed page shorter than the viewport.
The script now waits for committed frames and expands actual disk content before
checking scrolling. These were corrected in the check script.

Reproduce with Playwright and Chrome available:

```sh
PLAYWRIGHT_MODULE=/tmp/unraid-primary-pages-check/node_modules/playwright/index.mjs \
  node docs/validation/2026-10-25-tab-swipe/browser-check.mjs
```

The local server used:

```sh
go run -overlay=/tmp/unraid-primary-pages-check/overlay.json ./cmd/server
```

The temporary overlay serves `web/dist` from `127.0.0.1:18081` and supplies
synthetic snapshots. `CHECK_BASE_URL`, `CHROME_EXECUTABLE` and
`PLAYWRIGHT_MODULE` can change the script's local environment.

`sh scripts/verify-image.sh unraid-mobile:local` exited `127`: Docker is not
installed in this macOS environment. No image build or container smoke check
has passed. Production deployment and a real Unraid host were not tested.

physical devices. The README checklist still requires vertical scrolling,
bottom gestures, edge-back, pinch zoom, Sheet close/exit isolation, navigation
