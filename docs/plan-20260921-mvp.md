
# 1. 产品定位

产品定义建议直接定成：

> **一个专门为手机设计的 Unraid 实时状态与基础运维控制台。**

它不是缩小版 Unraid WebGUI，也不是完整 NAS 管理后台。

用户打开之后主要解决三件事：

1. **现在服务器状态怎么样**
2. **Docker / VM / Storage 当前运行得怎么样**
3. **出现问题时，可以快速执行基础运维操作**

V1 的核心原则：

**Observe first, operate second.**

也就是：

```text
实时状态可见性
      ↓
快速发现问题
      ↓
简单执行操作
      ↓
明确看到执行状态
```

不承担复杂配置、Docker 编辑、Share 管理、系统设置等低频能力。

# 4. 实时指标的数据策略

这里建议修改我们之前一个初始想法。

你选了：

> 请求时实时采集

但实际做 UI 的时候，CPU 和网络速率必须依赖两个时间点的 delta，否则没有办法得到准确的瞬时 rate。

因此后端内部还是应该维护一个非常轻量的 sampler。

不是历史监控系统。

只是：

```text
Ticker 1s
  ↓
读取 /proc
  ↓
计算 delta
  ↓
保存 LatestSnapshot
  ↓
SSE
```

内存里最多保留几十秒。

例如：

```go
type MetricsSnapshot struct {
    Timestamp     time.Time
    CPUUsage      float64
    CPUTemp       float64
    MemoryUsed    uint64
    MemoryTotal   uint64
    NetworkRXRate uint64
    NetworkTXRate uint64
}
```

绝对不要：

```text
Prometheus
InfluxDB
TimescaleDB
```

V1 完全没有必要。

# 14. Bottom Navigation

建议：

```text
 Home     Docker      VM      Storage
  ●
```

固定底栏。

注意 iPhone：

```css
padding-bottom: env(safe-area-inset-bottom);
```

高度建议：

```text
49–56px + Safe Area
```

Tab 切换：

**没有横向 slide。**

可以轻微：

```text
opacity
scale
```

但应该非常弱。

2026-10-25 一级 Tab 增量规则：

- 页面正文与底栏支持单指左右滑动，顺序为 Home → Docker → VM → Storage；
  左滑向后、右滑向前，首尾不循环，松手时最多切换一项。导航 pending 时忽略新滑动。
- 方向识别起点为 12px，水平优势为 1.5 倍；触发距离为 60px，
  或至少 24px 且同方向速度达到 600px/s。浏览器视口左右 24px 留给系统边缘手势。
  这些是新增的初始参数，真机调整时同步修改测试。
- 正文控件、横向滚动区域、顶部状态及连接/更新提示不参与；保留纵向滚动和双指缩放。
  底栏链接可以作为起点，有效横滑即使处于首尾也只抑制该手势的点击。
- AppSheet 的 Portal 内容、遮罩及退出动画 DOM 均阻挡 Tab 手势；
  弹层出现、切页、进入后台或退出会话时清除尚未结束的手势。
- 仅在新路由内容提交后，对稳定的单一 Outlet 播放 220ms opacity 入场；
  不保留退出页面，不预加载邻页，不播放横向推入。首次打开与数据刷新不重播。
  减少动画时取消淡入，但保留 Tab 滑动；Sheet 原有减少动画策略不变。
- 验收保留 Home 同时订阅 Docker、VM、Storage 的基线，以及独立页面各自查询、
  单一 System SSE、共享缓存和原有轮询周期。自动化结果与 Android Chrome、
  iOS Safari、已安装 PWA 的真机纵向滚动、底栏滑动、边缘返回、Sheet 关闭和流畅度检查分别记录。

页面层级下钻：

```text
Storage → Array
```

才使用 push/pop。

# 18. Query + SSE 数据模型

REST 用于 snapshot：

```text
GET /api/v1/system
GET /api/v1/docker
GET /api/v1/vms
GET /api/v1/storage
```

SSE：

```text
GET /api/v1/events
```

客户端启动：

```text
1. GET initial snapshot
2. render
3. open SSE
4. merge incremental events
```

不要把每秒整个 server state JSON 发回来。

应该 event based：

```json
{
  "type": "system.metrics",
  "data": {
    "cpu": 23.4,
    "memory": 48.1
  }
}
```

例如：

```text
system.metrics
docker.stats
docker.state
vm.state
storage.io
array.state
parity.progress
```

# 20. Operation 模型

强烈建议引入统一 Operation abstraction：

```go
type Operation struct {
    ID        string
    Type      string
    Resource  string

    State     OperationState
    StartedAt time.Time
    EndedAt   *time.Time

    Progress  *float64
    Error     *OperationError
}
```

State：

```text

running
success
failed
cancelled
```

这会统一：

```text
Docker Restart
VM Stop
Array Stop
Parity Check
```

前端就不用每一种操作重新设计状态机制。

# 23. Unraid Provider 机制

这是长期兼容性的核心。

不要：

```go
if version >= 7.0 {
   ...
}
```

而是：

```text
Startup
   ↓
Capability Detector
   ↓
Probe providers
   ↓
Select working provider
```

比如：

```go
type ArrayProvider interface {
    Probe(ctx context.Context) bool
    State(ctx context.Context) ...
    Start(ctx context.Context) ...
    Stop(ctx context.Context) ...
}
```

启动时：

```text
Native
  ↓ fail

WebGUI
  ↓ success

→ use WebGUI
```

版本号：

只用于：

```text
debug
telemetry
troubleshooting
```

而不是决定逻辑。

# 36. 不建议做离线 Service Worker 数据缓存

PWA ≠ offline app。

**本来就无法工作。**

所以 Service Worker 只负责：

```text

```

```text

```

否则很容易产生：

# 37. 安全

你选择了：

```text
privileged: true
```

那 V1 可以接受，但要明确：

**这个 Web 服务具有接近 Host Root 的能力。**

因此至少必须做到：

### 1. 不提供任何通用 Shell API

禁止：

```text
POST /exec
```

---

### 2. 所有 host command 必须静态定义

类似：

```go
func StopArray()
```

而不是：

```go
func Execute(command string)
```

---

### 3. 参数白名单

Docker ID：

只允许：

```text
实际存在 container ID
```

不要把 URL 参数直接拼进 shell。

---

### 4. Web Server 默认 LAN exposure

默认：

```text
0.0.0.0:PORT
```

但产品文档明确推荐：

```text
LAN
Tailscale
WireGuard
```

不要裸公网暴露。

# 38. Authentication

V1 你选择不做复杂认证。

但因为 privileged，我建议最少保留一个极轻量保护。

比如环境变量：

```text

```

如果设置：

API 要：

```text

```

如果未设置：

LAN mode。

这样不影响 V1 体验，又给 Tailscale 用户一个最基本的选择。

但这可以做成：

**P1，不阻塞最初 MVP。**

# 39. Docker Compose

    ports:
      - "8080:8080"

    volumes:
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
